# SETUNA2 との機能差分 (ギャップ分析)

本書は、SnapTack が後継を目指す **SETUNA2** (ClearUnit, 2008) の公式ヘルプと、SnapTack の現行仕様
(`SPEC.md` / `SPEC-v1.x.md` / `SPEC-v1.5.md`、M17 完了 = v1.5 時点) を突き合わせ、
**SETUNA2 にあって SnapTack に無い機能** を洗い出したものである。

- 出典: SETUNA2 公式ヘルプ (トップ / スタイルアイテム / オプション / コマンドライン / 初期設定スタイル)。
  現在は `web.archive.org` 上のアーカイブでのみ参照可能。
- 目的: v1.6 以降の実装候補の棚卸し。**本書は SPEC ではなく調査資料**であり、実装を約束するものではない。
- SETUNA2 の設計の核は **「スクラップスタイル」** — 外観・加工・出力を組み合わせた設定に任意の
  ショートカットキーを割り当てる仕組み。機能の大半がこの上に載っている。SnapTack はこの枠組みを持たない。

## 凡例

| 記号 | 意味 |
|---|---|
| ✅ | SnapTack に同等機能あり |
| 🔺 | 部分的にあり(SETUNA2 の方が高機能) |
| ❌ | SnapTack に無い |
| — | 実装意義が薄い(サービス終了等) |

## 1. スクラップの加工・変形

| SETUNA2 (原文) | 内容 | SnapTack |
|---|---|---|
| スクラップの拡大縮小 | スケール指定でリサイズ(絶対値/相対値)。最大 2 倍まで拡大も可 | ❌ 等倍固定 (`SPEC.md` 4.4) |
| 回転と反転 | 90/180/270 度回転、水平/垂直反転 | ❌ |
| トリム | 作成後のスクラップの不要部分をカット(範囲指定→Enter) | ❌ 編集はスコープ外 (`SPEC-v1.5.md` 5) |
| フレーム(枠) | ウインドウ枠 / 単色枠(色・太さ) / 立体枠 を切替 | ❌ 1px グレー枠固定 |
| 透過対応(絶対値/相対値) | 透過率で下の情報を透けさせる。プレビューあり | 🔺 不透明度ホイールあり。絶対値指定・プレビュー・スタイル化は無し |

## 2. 出力・保存

| SETUNA2 (原文) | 内容 | SnapTack |
|---|---|---|
| 保存形式の選択 (BMP/JPEG/PNG) | 3 形式。JPEG は品質指定可 | 🔺 PNG のみ |
| 枠を含めて保存 / コピー(枠付き) | フレーム込みで出力 (`Ctrl+Shift+C` / `Ctrl+Shift+S`) | ❌ 常に元画像そのまま |
| すぐ保存(日時で自動命名・指定フォルダへ) | ダイアログ無しの即保存 | ❌ 必ず `SaveFileDialog` (`SPEC-v1.x.md` 2.1) |
| 保存したファイルパスをクリップボードにコピー | 保存後にパス取得 | ❌ |
| 貼り付け (Ctrl+V) | クリップボード画像からスクラップ作成 | ❌ |

## 3. スクラップの作成方法

SETUNA2 は範囲選択**以外**の作成経路を持つ。SnapTack はキャプチャのみ。

| SETUNA2 (原文) | SnapTack |
|---|---|
| クリップボード内の画像から作成 | ❌ |
| クリップボード内の画像ファイルのフルパスから作成 | ❌ |
| 画像ファイルのドラッグ&ドロップで作成(exe へ / スクラップへ) | ❌ |

## 4. コマンドライン操作

`SETUNA.exe` に引数を渡して外部から操作。SnapTack は CLI 無し。

| コマンド | 動作 | SnapTack |
|---|---|---|
| `SETUNA.exe "C:\pic.jpg"` | 画像ファイルからスクラップ作成 | ❌ |
| `SETUNA.exe /R:X,Y,W,H` | 座標・サイズ指定でスクラップ作成 | ❌ |
| `SETUNA.exe /C:Capture` | キャプチャモードへ | ❌ |
| `SETUNA.exe /C:Option` | オプション画面を開く | ❌ |

## 5. 表示タイプ・状態

| SETUNA2 (原文) | 内容 | SnapTack |
|---|---|---|
| ウインドウタイプ | 付箋型でなく通常ウィンドウ(タスクバー格納・最前面 on/off) | ❌ 常に Topmost・タスクバー非表示 |
| コンパクト (50×50) | ダブルクリックで小型化。不透明度・枠を個別指定可 | ✅ サイコロ化 48×48 (`SPEC-v1.x.md` 2.3)。ほぼ同等 |
| 移動値の表示 / キー移動 | 座標を数値表示しながら移動。1px / 50px のキー移動 | ❌ ドラッグのみ、キー移動なし |

## 6. キャプチャ準備中(範囲選択)

| SETUNA2 (原文) | 内容 | SnapTack |
|---|---|---|
| キャプチャ設定(選択範囲のスタイル) | 枠を実線・透過度 100% にして描画負荷を軽減する設定 | ❌ 選択オーバーレイの見た目は設定化していない |

> SETUNA(初代)にはルーペ(選択中の拡大表示)があったが、SETUNA2 公式ヘルプのオプション項目では
> スタイル/負荷設定に整理されている。ピクセル精密指定の補助は SnapTack に無い。

## 7. オプション(設定)項目

| SETUNA2 (原文) | 内容 | SnapTack |
|---|---|---|
| 動作タイプ | タスクバー常駐アプリ型 / タスクトレイ常駐型 の切替 | ❌ トレイ常駐固定 |
| 二重起動時の動作 | 既起動中に exe を開いたらキャプチャモードにする | ❌ 二重起動は即終了 (`SPEC.md` 4.1) |
| スプラッシュウィンドウ | 起動時ロゴ表示 | ❌(不要と判断可) |
| 初期状態に戻す | 設定リセット | ❌ |
| 基本スタイル / Wクリック時スタイル | 新規作成時・ダブルクリック時に適用するスタイルの指定 | ❌ スタイル機構が無い |
| 非選択時の効果 | マウスが乗っていない時の透明度 | ❌ |
| スクラップの最大数(枚数) | 同時表示枚数の設定 | 🔺 保持数上限あり(`MaxScraps`)。表示枚数の概念は無い |

## 8. スタイル機構(最大の設計差)

| SETUNA2 (原文) | 内容 | SnapTack |
|---|---|---|
| スクラップスタイルの新規作成・編集 | スタイルアイテムを積み重ねて自作 | ❌ |
| スクラップメニューの編集 | 右クリックメニューの並べ替え・削除・自作スタイル追加 | ❌ 固定 |
| 任意ショートカットキーの割り当て | スタイルごと、複数キー可 | ❌ 固定 |

SETUNA2 の初期設定スタイルだけでも約 40 のキー割り当てがある(抜粋):

| キー | 動作 |
|---|---|
| `R` | 右に 90 度回転 |
| `Alt+↑` / `Alt+Shift+↑` | 10% / 1% 拡大 |
| `Alt+↓` / `Alt+Shift+↓` | 10% / 1% 縮小 |
| `Alt+←` / `Alt+→` | 透明度を 10% 上げ / 下げ |
| `↑↓←→` / `Shift+方向` | 1px / 50px 移動 |
| `1` / `2` / `3` | 立体枠 / 単色枠 / ウインドウ化 |
| `5`〜`0` | 倍率 50〜100% |
| `L` | 枠無し |
| `Ctrl+Shift+C` / `Ctrl+Shift+S` | 枠付きコピー / 枠付き保存 |
| `Ctrl+V` | 貼り付け(クリップボードから作成) |
| `Q` | 閉じる |

| SETUNA2 (原文) | SnapTack |
|---|---|
| Picasa アップロード | — サービス終了済み。実装意義なし |

## SnapTack が SETUNA2 に対して優る点(参考)

差分だけでは不公平なため併記する。

- **永続化 + 起動時復元** — SETUNA2 は再起動で全消失。SnapTack の明確な優位 (`SPEC-v1.5.md` 2.4)。
- **スクラップリスト** — サムネイル一覧・複数選択・ゴミ箱タブ・グリッド/リスト切替。SETUNA2 は簡易一覧のみ。
- **多言語 (英/日)** / **Per-Monitor V2 の混在 DPI 対応** — .NET 2.0 / XP 世代の SETUNA2 より現代的。
- **ゴミ箱** — 両者にあり(同等)。

## 実装候補の優先度(所見)

コスト・実用価値・SPEC との整合を踏まえた提案。詳細は `MILESTONES-v1.6.md` を参照。

割り当て済みのリリース: **v1.6** = 保存強化 + 作成方法追加 / **v1.7** = 編集 /
**v1.8 または v2.0(未定)** = スタイル機構。

| 優先 | 機能 | 根拠 |
|---|---|---|
| 高 | 保存形式選択 (JPEG/BMP) + 即保存 + 日時自動命名 | 既存保存処理の拡張で低コスト・実用価値大 |
| 高 | 貼り付け / D&D によるスクラップ作成 | キャプチャ資産を流用でき、後継として自然 |
| 中 | キー移動・移動値表示 | 微調整の実用機能。低〜中コスト |
| 中 | 拡大縮小(→ 回転・反転) | `SPEC` で v2.0+「スクラップの編集」に位置づけ済み。実装量大 |
| 中 | フレーム(枠タイプ)・ウインドウタイプ | v2.0+「スタイル機能」の一部 |
| 低 | コマンドライン操作 | 用途が限定的。ランチャー連携が要るなら |
| 低 | スタイル機構(自作スタイル + キー割り当て) | SETUNA2 の核だが実装量が最大。上記を個別機能で満たせば必須ではない |
| — | Picasa アップロード | サービス終了。実装しない |

> **差分の中核は「スタイル機構」と「画像編集」**であり、いずれも SnapTack の `SPEC.md` 6章が
> 「スクラップの編集」「スタイル機能」として既に意識している領域と重なる。
> ただし同章はこれらを **v2.0+** に分類しているため、上記のリリース割り当て(編集 = v1.7 等)とは
> 現状ズレている。SPEC 側の更新要否は別途判断する。
